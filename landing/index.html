Philosophy

Compose libraries.
Own your code.

Every library is independently replaceable. If one goes unmaintained, swap that single piece — not your entire project. NuGet install, dotnet restore, ship. No git submodules. No compiling 50,000 lines of framework source you'll never read.
Monolithic frameworks
  • 50,000+ lines of framework source code
  • Git submodule dependency management
  • Framework dies when maintainer leaves
  • Deep coupling — can't swap subsystems
  • Framework upgrades break your game
Composed libraries
  • ~1,000 lines of glue you fully understand
  • NuGet packages — dotnet restore and go
  • Each library maintained independently
  • Swap any single piece without rewiring
  • Upgrade one package at a time

Get Started

Zero to rendering in 5 minutes

Create your MonoGame project
dotnet new mgdesktopgl -o MyGame
Install the core stack
dotnet add package Arch --version 2.1.0 dotnet add package Arch.System --version 1.1.0 dotnet add package MonoGame.Extended --version 5.3.1 dotnet add package Apos.Input --version 2.5.0 dotnet add package FontStashSharp.MonoGame --version 1.3.7
Copy the glue code
~1,000 lines from the G1 guide. SceneManager, RenderLayers, SpatialHash, TweenSystem, ObjectPool — everything wired and ready.
Read the docs that matter to your genre
Platformer? Start with G3 (collision) + C2 (game feel). RPG? G4 (AI) + G10 (inventory, dialogue). Top-down? G28 + G20 (camera).
